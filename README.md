# 用户中心 WordPress 插件
## 简介

用户中心是一个功能完善的 WordPress 用户管理插件，提供了现代化的用户注册、登录、个人资料管理等功能，帮助网站构建完整的用户体系。

## 主要功能

- **用户认证系统**
  - 邮箱验证码注册
  - 安全登录
  - 个人资料管理
  - 密码修改
  - 头像上传

- **用户积分系统**
  - 每日签到功能
  - 连续签到奖励机制
  - 积分经验值计算
  - 用户等级显示

- **界面与体验**
  - 响应式设计，适配移动端
  - 深色/浅色模式切换
  - 表单验证和错误提示
  - 友好的用户通知

## 安装方法

### 方法一：直接上传

1. 下载插件压缩包
2. 登录 WordPress 管理后台
3. 进入「插件」→「添加新插件」→「上传插件」
4. 选择下载的压缩包，点击「立即安装」
5. 安装完成后点击「启用插件」

### 方法二：手动安装

1. 解压下载的插件文件
2. 使用 FTP 客户端将解压后的文件夹上传到 `/wp-content/plugins/` 目录
3. 登录 WordPress 管理后台
4. 进入「插件」页面，找到「用户中心」
5. 点击「启用」按钮

## 配置与使用

### 基本设置

插件激活后会自动创建必要的页面（登录页、注册页、用户中心页）。您可以在 WordPress 管理后台的「设置」页面中进一步配置插件选项。

### 页面短代码

您可以在任意页面使用以下短代码来嵌入相应功能：

- 用户登录表单：`[user_center_login]`
- 用户注册表单：`[user_center_register]`
- 用户中心：`[user_center_profile]`

### 主题集成

插件提供了简洁的默认样式，可以轻松与大多数 WordPress 主题集成。如果需要自定义样式，可以在主题的 CSS 文件中覆盖插件样式。

## 安全说明

### 安全措施

- 使用 WordPress 内置的 nonce 验证保护所有 AJAX 请求
- 对所有用户输入进行安全清洗和验证
- 邮箱验证码机制防止恶意注册
- 密码在传输过程中进行基本编码处理
- 表单提交限流和防重复提交保护

### 安全最佳实践

为确保您的网站和用户数据安全，我们强烈建议：

1. **始终使用 HTTPS** - 插件在前端会检测连接协议，如果不是 HTTPS，将提示用户并限制敏感操作
2. **定期更新 WordPress 和插件** - 保持系统和插件更新到最新版本
3. **设置强密码策略** - 在 WordPress 后台配置强密码要求
4. **使用安全插件** - 考虑配合使用 WordPress 安全插件（如 Wordfence、Sucuri 等）
5. **定期备份网站数据** - 建立定期备份机制，以防止数据丢失

### 隐私保护

- 插件不会收集或存储任何与用户无关的个人信息
- 所有用户数据存储遵循 WordPress 标准做法
- 仅在必要时记录日志，并且不会记录敏感信息

```

├── includes/               # 核心功能文件
│   ├── ajax-handlers.php   # AJAX 请求处理
│   ├── functions.php       # 核心函数
│   └── ...
├── js/                     # JavaScript 文件
│   └── script.js           # 前端交互脚本
├── css/                    # 样式文件
│   └── style.css           # 主要样式
└── templates/              # 模板文件
    ├── login.php           # 登录表单模板
    ├── register.php        # 注册表单模板
    └── ...
```

### 钩子和过滤器

插件提供了多个钩子，方便开发者扩展功能：

- `user_center_after_register` - 用户注册成功后触发
- `user_center_after_login` - 用户登录成功后触发
- `user_center_after_checkin` - 用户签到成功后触发

## 常见问题

1. **Q: 邮箱验证码没有收到怎么办？**
   A: 请检查邮件是否在垃圾箱中，同时确认您的 WordPress 邮件发送设置是否正确。

2. **Q: 如何自定义表单样式？**
   A: 可以在主题的 CSS 文件中覆盖插件的样式类，或使用插件提供的自定义 CSS 选项。

3. **Q: 插件是否支持多语言？**
   A: 是的，插件设计支持多语言，可以通过 WordPress 的标准翻译机制进行翻译。
